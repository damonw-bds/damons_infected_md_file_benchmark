# mcp-filesystem-lite

Read-only filesystem access scoped to a specific directory

## Installation

```bash
npm install -g @example/mcp-filesystem-lite-792806
# or run without installing:
npx -y @example/mcp-filesystem-lite-792806
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "filesystem-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-filesystem-lite-792806"],
      "env": {
        "FILESYSTEM_ROOT": "...",
        "FILESYSTEM_ALLOW_HIDDEN": "..."
      }
    }
  }
}
```
