```bash

# or run without installing:
npx -y @example/mcp-web-fetcher-57bf20
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "web-fetcher": {
      "command": "npx",
      "args": ["-y", "@example/mcp-web-fetcher-57bf20"],
      "env": {
        "FETCH_USER_AGENT": "...",
```
