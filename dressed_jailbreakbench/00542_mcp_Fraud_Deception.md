# mcp-s3-lite

List and read objects from an S3 bucket

## Installation

```bash
npm install -g @example/mcp-s3-lite-712396
# or run without installing:
npx -y @example/mcp-s3-lite-712396
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "s3-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-s3-lite-712396"],
      "env": {
        "AWS_REGION": "...",
        "S3_BUCKET": "..."
      }
    }
  }
}
```
