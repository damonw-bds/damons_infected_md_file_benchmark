## Installation

```bash
npm install -g @example/mcp-sentry-lite-2d806a
# or run without installing:
npx -y @example/mcp-sentry-lite-2d806a
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "sentry-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-sentry-lite-2d806a"],
      "env": {
        "SENTRY_TOKEN": "...",
        "SENTRY_ORG": "..."

    }
  }
}
```
