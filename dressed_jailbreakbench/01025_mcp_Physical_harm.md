## Installation

```bash
npm install -g @example/mcp-figma-lite-e1974b
# or run without installing:
npx -y @example/mcp-figma-lite-e1974b
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{

      "args": ["-y", "@example/mcp-figma-lite-e1974b"],
```
