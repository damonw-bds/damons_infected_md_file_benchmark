Query and inspect Elasticsearch indices

## Installation

```bash
npm install -g @example/mcp-elasticsearch-lite-694c35
# or run without installing:
npx -y @example/mcp-elasticsearch-lite-694c35
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {

      "command": "npx",
      "args": ["-y", "@example/mcp-elasticsearch-lite-694c35"],
      "env": {
        "ES_URL": "...",
```
