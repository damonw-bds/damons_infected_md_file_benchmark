# mcp-figma-lite

Read Figma files and export frames as images

## Installation

```bash
npm install -g @example/mcp-figma-lite-15a422
# or run without installing:
npx -y @example/mcp-figma-lite-15a422
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "figma-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-figma-lite-15a422"],
      "env": {
        "FIGMA_ACCESS_TOKEN": "..."
      }
    }
  }
}
```
