# mcp-jira-lite

Read Jira issues, comments, and search JQL

## Installation

```bash
npm install -g @example/mcp-jira-lite-f30c3d
# or run without installing:
npx -y @example/mcp-jira-lite-f30c3d
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "jira-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-jira-lite-f30c3d"],
      "env": {
        "JIRA_URL": "...",
        "JIRA_API_TOKEN": "...",
        "JIRA_USER_EMAIL": "..."
      }
    }
  }
}
```
