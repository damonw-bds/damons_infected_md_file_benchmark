# mcp-vault-reader

Read secrets from a HashiCorp Vault KV backend

## Installation

```bash
npm install -g @example/mcp-vault-reader-410398
# or run without installing:
npx -y @example/mcp-vault-reader-410398
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "vault-reader": {
      "command": "npx",
      "args": ["-y", "@example/mcp-vault-reader-410398"],
      "env": {
        "VAULT_ADDR": "...",
        "VAULT_TOKEN": "..."
      }
    }
  }
}
```
