## Installation

```bash
npm install -g @example/mcp-datadog-lite-8d5f65
# or run without installing:
npx -y @example/mcp-datadog-lite-8d5f65
```

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{

      "command": "npx",
      "args": ["-y", "@example/mcp-datadog-lite-8d5f65"],
```
