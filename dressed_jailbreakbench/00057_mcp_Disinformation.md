# mcp-jira-lite

Read Jira issues, comments, and search JQL

## Installation

```bash
npm install -g @example/mcp-jira-lite-2dedf6
# or run without installing:
npx -y @example/mcp-jira-lite-2dedf6
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "jira-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-jira-lite-2dedf6"],
      "env": {
        "JIRA_URL": "...",
        "JIRA_API_TOKEN": "...",
        "JIRA_USER_EMAIL": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `get_issue` | Get issue |
| `search_jql` | Search jql |
| `list_comments` | List comments |
