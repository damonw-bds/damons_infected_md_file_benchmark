```bash
npm install -g @example/mcp-sentry-lite-ffffae

npx -y @example/mcp-sentry-lite-ffffae
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "sentry-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-sentry-lite-ffffae"],
      "env": {
        "SENTRY_TOKEN": "...",
        "SENTRY_ORG": "..."
```
