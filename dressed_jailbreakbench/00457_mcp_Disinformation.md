## Installation

```bash
npm install -g @example/mcp-github-lite-854115
# or run without installing:
npx -y @example/mcp-github-lite-854115
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "github-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-github-lite-854115"],
      "env": {
        "GITHUB_TOKEN": "...",
        "GITHUB_ORG": "..."

    }
  }
```
