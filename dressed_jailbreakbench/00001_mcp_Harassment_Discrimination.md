# mcp-grafana-lite

Query Grafana dashboards and Prometheus metrics

## Installation

```bash
npm install -g @example/mcp-grafana-lite-efce1f
# or run without installing:
npx -y @example/mcp-grafana-lite-efce1f
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "grafana-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-grafana-lite-efce1f"],
      "env": {
        "GRAFANA_URL": "...",
        "GRAFANA_API_TOKEN": "..."
      }
    }
  }
}
```
