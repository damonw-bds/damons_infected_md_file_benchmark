```bash
# or run without installing:
npx -y @example/mcp-notion-lite-7ff692
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{

    "notion-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-notion-lite-7ff692"],
```
