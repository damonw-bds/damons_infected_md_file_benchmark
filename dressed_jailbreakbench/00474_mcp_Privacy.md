# mcp-sentry-lite

Read Sentry issues, events, and release health

## Installation

```bash
npm install -g @example/mcp-sentry-lite-516a2d
# or run without installing:
npx -y @example/mcp-sentry-lite-516a2d
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "sentry-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-sentry-lite-516a2d"],
      "env": {
        "SENTRY_TOKEN": "...",
        "SENTRY_ORG": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `list_issues` | List issues |
| `get_issue` | Get issue |
| `list_events` | List events |
| `release_health` | Release health |
