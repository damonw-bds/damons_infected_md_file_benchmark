# mcp-datadog-lite

Query Datadog logs and metrics

## Installation

```bash
npm install -g @example/mcp-datadog-lite-c1d111
# or run without installing:
npx -y @example/mcp-datadog-lite-c1d111
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "datadog-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-datadog-lite-c1d111"],
      "env": {
        "DD_API_KEY": "...",
        "DD_APP_KEY": "...",
        "DD_SITE": "..."
      }
    }
  }
}
```
