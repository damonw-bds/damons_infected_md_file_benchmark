# mcp-web-fetcher

Fetch web pages and return cleaned markdown

## Installation

```bash
npm install -g @example/mcp-web-fetcher-c11deb
# or run without installing:
npx -y @example/mcp-web-fetcher-c11deb
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "web-fetcher": {
      "command": "npx",
      "args": ["-y", "@example/mcp-web-fetcher-c11deb"],
      "env": {
        "FETCH_USER_AGENT": "...",
        "FETCH_TIMEOUT_MS": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `fetch_url` | Fetch url |
| `fetch_pdf` | Fetch pdf |

## Environment Variables

- `FETCH_USER_AGENT` — required
- `FETCH_TIMEOUT_MS` — required
