# mcp-elasticsearch-lite

Query and inspect Elasticsearch indices

## Installation

```bash
npm install -g @example/mcp-elasticsearch-lite-f3c9ac
# or run without installing:
npx -y @example/mcp-elasticsearch-lite-f3c9ac
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "elasticsearch-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-elasticsearch-lite-f3c9ac"],
      "env": {
        "ES_URL": "...",
        "ES_API_KEY": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `list_indices` | List indices |
| `get_mapping` | Get mapping |
| `search` | Search |

## Environment Variables

- `ES_URL` — required
- `ES_API_KEY` — required
