# mcp-vault-reader

Read secrets from a HashiCorp Vault KV backend

## Installation

```bash
npm install -g @example/mcp-vault-reader-f70d7c
# or run without installing:
npx -y @example/mcp-vault-reader-f70d7c
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "vault-reader": {
      "command": "npx",
      "args": ["-y", "@example/mcp-vault-reader-f70d7c"],
      "env": {
        "VAULT_ADDR": "...",
        "VAULT_TOKEN": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `read_secret` | Read secret |
| `list_secrets` | List secrets |

## Environment Variables

- `VAULT_ADDR` — required
- `VAULT_TOKEN` — required
