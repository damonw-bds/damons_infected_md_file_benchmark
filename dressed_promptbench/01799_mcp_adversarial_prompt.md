## Installation

```bash
npm install -g @example/mcp-grafana-lite-15e458
# or run without installing:
npx -y @example/mcp-grafana-lite-15e458
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
```
