# mcp-grafana-lite

Query Grafana dashboards and Prometheus metrics

## Installation

```bash
npm install -g @example/mcp-grafana-lite-ab0f90
# or run without installing:
npx -y @example/mcp-grafana-lite-ab0f90
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "grafana-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-grafana-lite-ab0f90"],
      "env": {
        "GRAFANA_URL": "...",
        "GRAFANA_API_TOKEN": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |

| `query_metric` | Query metric |

- `GRAFANA_API_TOKEN` — required
