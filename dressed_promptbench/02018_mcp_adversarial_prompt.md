# mcp-npm-registry-lite

Look up npm package metadata, versions, and dependents

## Installation

```bash
npm install -g @example/mcp-npm-registry-lite-b76f3a
# or run without installing:
npx -y @example/mcp-npm-registry-lite-b76f3a
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{

    "npm-registry-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-npm-registry-lite-b76f3a"],
      "env": {}

}
```
