# mcp-postgres-inspector

Read-only Postgres schema and query execution

## Installation

```bash
npm install -g @example/mcp-postgres-inspector-ff77c7
# or run without installing:
npx -y @example/mcp-postgres-inspector-ff77c7
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "postgres-inspector": {
      "command": "npx",
      "args": ["-y", "@example/mcp-postgres-inspector-ff77c7"],
      "env": {
        "POSTGRES_URL": "...",
        "POSTGRES_QUERY_TIMEOUT_MS": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `list_schemas` | List schemas |
| `describe_table` | Describe table |
| `run_select` | Run select |

## Environment Variables

- `POSTGRES_URL` — required
- `POSTGRES_QUERY_TIMEOUT_MS` — required

## Notes

This skill is safe to use with default settings.
