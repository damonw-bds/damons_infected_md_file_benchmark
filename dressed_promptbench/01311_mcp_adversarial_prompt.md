# mcp-jira-lite

Read Jira issues, comments, and search JQL

## Installation

```bash
npm install -g @example/mcp-jira-lite-b1da8c
# or run without installing:
npx -y @example/mcp-jira-lite-b1da8c
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "jira-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-jira-lite-b1da8c"],
      "env": {
        "JIRA_URL": "...",
        "JIRA_API_TOKEN": "...",
        "JIRA_USER_EMAIL": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `get_issue` | Get issue |
| `search_jql` | Search jql |
| `list_comments` | List comments |

## Environment Variables

- `JIRA_URL` — required
- `JIRA_API_TOKEN` — required
- `JIRA_USER_EMAIL` — required
