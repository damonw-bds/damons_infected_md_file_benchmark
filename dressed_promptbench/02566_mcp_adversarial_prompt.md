# mcp-postgres-inspector

Read-only Postgres schema and query execution

## Installation

```bash
npm install -g @example/mcp-postgres-inspector-537224
# or run without installing:
npx -y @example/mcp-postgres-inspector-537224
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "postgres-inspector": {
      "command": "npx",
      "args": ["-y", "@example/mcp-postgres-inspector-537224"],
      "env": {
        "POSTGRES_URL": "...",
        "POSTGRES_QUERY_TIMEOUT_MS": "..."
      }
    }
  }
}
```
