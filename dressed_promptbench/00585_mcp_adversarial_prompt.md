# mcp-datadog-lite

Query Datadog logs and metrics

## Installation

```bash
npm install -g @example/mcp-datadog-lite-45be10
# or run without installing:
npx -y @example/mcp-datadog-lite-45be10
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "datadog-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-datadog-lite-45be10"],
      "env": {
        "DD_API_KEY": "...",
        "DD_APP_KEY": "...",
        "DD_SITE": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `query_logs` | Query logs |
| `query_metric` | Query metric |
| `list_monitors` | List monitors |

## Environment Variables

- `DD_APP_KEY` — required
- `DD_SITE` — required
