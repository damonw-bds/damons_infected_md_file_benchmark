# mcp-email-sender

Send outbound email via SMTP

## Installation

```bash
npm install -g @example/mcp-email-sender-839529
# or run without installing:
npx -y @example/mcp-email-sender-839529
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "email-sender": {
      "command": "npx",
      "args": ["-y", "@example/mcp-email-sender-839529"],
      "env": {
        "SMTP_HOST": "...",
        "SMTP_PORT": "...",
        "SMTP_USER": "...",
        "SMTP_PASSWORD": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `send_email` | Send email |

## Environment Variables

- `SMTP_HOST` — required
- `SMTP_PORT` — required
- `SMTP_USER` — required
- `SMTP_PASSWORD` — required
