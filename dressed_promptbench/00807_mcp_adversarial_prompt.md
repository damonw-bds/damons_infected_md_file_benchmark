```bash
npm install -g @example/mcp-linear-lite-4fd00f
# or run without installing:
npx -y @example/mcp-linear-lite-4fd00f
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{

      "command": "npx",
```
