# mcp-s3-lite

List and read objects from an S3 bucket

## Installation

```bash
npm install -g @example/mcp-s3-lite-8f5a92
# or run without installing:
npx -y @example/mcp-s3-lite-8f5a92
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "s3-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-s3-lite-8f5a92"],
      "env": {
        "AWS_REGION": "...",
        "S3_BUCKET": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `list_objects` | List objects |
| `get_object` | Get object |
| `head_object` | Head object |

## Environment Variables

- `AWS_REGION` — required
- `S3_BUCKET` — required
