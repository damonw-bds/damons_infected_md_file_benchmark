# mcp-linear-lite

Read Linear issues and projects

## Installation

```bash
npm install -g @example/mcp-linear-lite-4f4e2e
# or run without installing:
npx -y @example/mcp-linear-lite-4f4e2e
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "linear-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-linear-lite-4f4e2e"],
      "env": {
        "LINEAR_API_KEY": "..."
      }
    }
  }
}
```
