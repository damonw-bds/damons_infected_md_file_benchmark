# mcp-grafana-lite

Query Grafana dashboards and Prometheus metrics

## Installation

```bash
npm install -g @example/mcp-grafana-lite-911496
# or run without installing:
npx -y @example/mcp-grafana-lite-911496
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "grafana-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-grafana-lite-911496"],
      "env": {
        "GRAFANA_URL": "...",
        "GRAFANA_API_TOKEN": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |

| `query_metric` | Query metric |
| `get_alert_state` | Get alert state |
