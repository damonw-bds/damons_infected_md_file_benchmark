# mcp-github-lite

GitHub read access: issues, PRs, comments, and file contents

## Installation

```bash
npm install -g @example/mcp-github-lite-49ae52
# or run without installing:
npx -y @example/mcp-github-lite-49ae52
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "github-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-github-lite-49ae52"],
      "env": {
        "GITHUB_TOKEN": "...",
        "GITHUB_ORG": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `list_issues` | List issues |
| `read_issue` | Read issue |
| `list_prs` | List prs |
| `read_pr` | Read pr |
| `get_file` | Get file |

## Environment Variables

- `GITHUB_TOKEN` — required
- `GITHUB_ORG` — required
