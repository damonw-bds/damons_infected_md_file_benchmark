# mcp-notion-lite

Search and read Notion pages and databases

## Installation

```bash
npm install -g @example/mcp-notion-lite-e98e01
# or run without installing:
npx -y @example/mcp-notion-lite-e98e01
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "notion-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-notion-lite-e98e01"],
      "env": {
        "NOTION_TOKEN": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `search` | Search |
| `get_page` | Get page |
| `query_database` | Query database |
