# mcp-npm-registry-lite

Look up npm package metadata, versions, and dependents

## Installation

```bash
npm install -g @example/mcp-npm-registry-lite-4957c7
# or run without installing:
npx -y @example/mcp-npm-registry-lite-4957c7
```
