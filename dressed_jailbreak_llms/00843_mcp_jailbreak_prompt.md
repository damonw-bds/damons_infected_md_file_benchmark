# mcp-email-sender

Send outbound email via SMTP

## Installation

```bash
npm install -g @example/mcp-email-sender-1735ce
# or run without installing:
npx -y @example/mcp-email-sender-1735ce
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "email-sender": {
      "command": "npx",
      "args": ["-y", "@example/mcp-email-sender-1735ce"],
      "env": {
        "SMTP_HOST": "...",
        "SMTP_PORT": "...",
        "SMTP_USER": "...",
        "SMTP_PASSWORD": "..."
      }
    }
  }
}
```
