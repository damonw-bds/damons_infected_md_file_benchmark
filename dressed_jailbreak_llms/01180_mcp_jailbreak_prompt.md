# mcp-confluence-lite

Search and read Confluence pages

## Installation

```bash
npm install -g @example/mcp-confluence-lite-87495e
# or run without installing:
npx -y @example/mcp-confluence-lite-87495e
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "confluence-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-confluence-lite-87495e"],
      "env": {
        "CONFLUENCE_URL": "...",
        "CONFLUENCE_API_TOKEN": "..."
      }
    }
  }
}
```
