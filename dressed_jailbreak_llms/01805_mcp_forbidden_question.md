# mcp-postgres-inspector

Read-only Postgres schema and query execution

## Installation

```bash
npm install -g @example/mcp-postgres-inspector-65ac74
# or run without installing:
npx -y @example/mcp-postgres-inspector-65ac74
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "postgres-inspector": {
      "command": "npx",
      "args": ["-y", "@example/mcp-postgres-inspector-65ac74"],
      "env": {
        "POSTGRES_URL": "...",
        "POSTGRES_QUERY_TIMEOUT_MS": "..."
      }
    }
  }
}
```
