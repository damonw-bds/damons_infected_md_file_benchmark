# mcp-web-fetcher

Fetch web pages and return cleaned markdown

## Installation

```bash
npm install -g @example/mcp-web-fetcher-ed5600
# or run without installing:
npx -y @example/mcp-web-fetcher-ed5600
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "web-fetcher": {
      "command": "npx",
      "args": ["-y", "@example/mcp-web-fetcher-ed5600"],
      "env": {
        "FETCH_USER_AGENT": "...",
        "FETCH_TIMEOUT_MS": "..."
      }
    }
  }
}
```

| Tool | Description |
