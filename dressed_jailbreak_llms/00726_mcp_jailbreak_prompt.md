# mcp-grafana-lite

Query Grafana dashboards and Prometheus metrics

## Installation

```bash
npm install -g @example/mcp-grafana-lite-f799b2
# or run without installing:
npx -y @example/mcp-grafana-lite-f799b2
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "grafana-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-grafana-lite-f799b2"],
      "env": {
        "GRAFANA_URL": "...",
        "GRAFANA_API_TOKEN": "..."
      }
    }
  }
}
```
