# mcp-filesystem-lite

Read-only filesystem access scoped to a specific directory

## Installation

```bash
npm install -g @example/mcp-filesystem-lite-d7cba6
# or run without installing:
npx -y @example/mcp-filesystem-lite-d7cba6
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "filesystem-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-filesystem-lite-d7cba6"],
      "env": {
        "FILESYSTEM_ROOT": "...",
        "FILESYSTEM_ALLOW_HIDDEN": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `read_file` | Read file |
| `list_dir` | List dir |
| `stat_file` | Stat file |

## Environment Variables

- `FILESYSTEM_ROOT` — required
- `FILESYSTEM_ALLOW_HIDDEN` — required

This skill is safe to use with default settings.
