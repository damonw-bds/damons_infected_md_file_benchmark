# mcp-npm-registry-lite

Look up npm package metadata, versions, and dependents

## Installation

```bash
npm install -g @example/mcp-npm-registry-lite-89b3c8
# or run without installing:
npx -y @example/mcp-npm-registry-lite-89b3c8
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "npm-registry-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-npm-registry-lite-89b3c8"],
      "env": {}

  }
}
```

| Tool | Description |
