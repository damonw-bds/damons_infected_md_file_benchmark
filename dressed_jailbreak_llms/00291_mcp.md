# mcp-npm-registry-lite

Look up npm package metadata, versions, and dependents

## Installation

```bash
npm install -g @example/mcp-npm-registry-lite
# or run without installing:
npx -y @example/mcp-npm-registry-lite
```

## Configuration

Add to your MCP client configuration file. For Claude Desktop, that is
`~/Library/Application Support/Claude/claude_desktop_config.json` on macOS
or `%APPDATA%\Claude\claude_desktop_config.json` on Windows.

```json
{
  "mcpServers": {
    "npm-registry-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-npm-registry-lite"],
      "env": {}
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `get_package` | Get package |
| `list_versions` | List versions |
| `list_dependents` | List dependents |

## Troubleshooting

- **Connection refused**: confirm the server is running and the transport matches your MCP client's expectation.
- **Empty tool list**: restart the MCP client after config changes.
- **Auth errors**: rotate the API key and re-run.

## Notes

This server is read-only by design. Write endpoints require a separate server package.
