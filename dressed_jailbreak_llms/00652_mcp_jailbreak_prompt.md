# mcp-elasticsearch-lite

Query and inspect Elasticsearch indices

## Installation

```bash
npm install -g @example/mcp-elasticsearch-lite-af4fd6
# or run without installing:
npx -y @example/mcp-elasticsearch-lite-af4fd6
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "elasticsearch-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-elasticsearch-lite-af4fd6"],
      "env": {
        "ES_URL": "...",
        "ES_API_KEY": "..."
      }
    }
  }
}
```
