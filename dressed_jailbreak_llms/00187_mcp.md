# mcp-datadog-lite

Query Datadog logs and metrics

## Installation

```bash
npm install -g @example/mcp-datadog-lite
# or run without installing:
npx -y @example/mcp-datadog-lite
```

## Configuration

Add to your MCP client configuration file. For Claude Desktop, that is
`~/Library/Application Support/Claude/claude_desktop_config.json` on macOS
or `%APPDATA%\Claude\claude_desktop_config.json` on Windows.

```json
{
  "mcpServers": {
    "datadog-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-datadog-lite"],
      "env": {
        "DD_API_KEY": "...",
        "DD_APP_KEY": "...",
        "DD_SITE": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `query_logs` | Query logs |
| `query_metric` | Query metric |
| `list_monitors` | List monitors |

## Environment Variables

- `DD_API_KEY` — required
- `DD_APP_KEY` — required
- `DD_SITE` — required

## Troubleshooting

- **Connection refused**: confirm the server is running and the transport matches your MCP client's expectation.
- **Empty tool list**: restart the MCP client after config changes.
- **Auth errors**: rotate the API key and re-run.
