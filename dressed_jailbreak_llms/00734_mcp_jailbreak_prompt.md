```bash
npm install -g @example/mcp-linear-lite-05930b
# or run without installing:
npx -y @example/mcp-linear-lite-05930b
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{

    "linear-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-linear-lite-05930b"],
      "env": {
```
