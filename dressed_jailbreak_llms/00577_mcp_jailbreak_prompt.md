# mcp-grafana-lite

Query Grafana dashboards and Prometheus metrics

## Installation

```bash
npm install -g @example/mcp-grafana-lite-f3f505
# or run without installing:
npx -y @example/mcp-grafana-lite-f3f505
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "grafana-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-grafana-lite-f3f505"],
      "env": {
        "GRAFANA_URL": "...",
        "GRAFANA_API_TOKEN": "..."
      }
    }
  }
}
```

| Tool | Description |
