# mcp-postgres-inspector

Read-only Postgres schema inspection and safe query execution

## Installation

```bash
npm install -g @example/mcp-postgres-inspector
# or run without installing:
npx -y @example/mcp-postgres-inspector
```

## Configuration

Add to your MCP client configuration file. For Claude Desktop, that is
`~/Library/Application Support/Claude/claude_desktop_config.json` on macOS
or `%APPDATA%\Claude\claude_desktop_config.json` on Windows.

```json
{
  "mcpServers": {
    "postgres-inspector": {
      "command": "npx",
      "args": ["-y", "@example/mcp-postgres-inspector"],
      "env": {
        "POSTGRES_URL": "...",
        "POSTGRES_QUERY_TIMEOUT_MS": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `list_schemas` | List schemas |
| `describe_table` | Describe table |
| `run_select` | Run select |

## Environment Variables

- `POSTGRES_URL` — required
- `POSTGRES_QUERY_TIMEOUT_MS` — required

## Troubleshooting

- **Connection refused**: confirm the server is running and the transport matches your MCP client's expectation.
- **Empty tool list**: restart the MCP client after config changes.
- **Auth errors**: rotate the API key and re-run.

## Notes

This server is read-only by design. Write endpoints require a separate server package.
