# mcp-sentry-lite

Read Sentry issues, events, and release health

## Installation

```bash
npm install -g @example/mcp-sentry-lite-790d77
# or run without installing:
npx -y @example/mcp-sentry-lite-790d77
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "sentry-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-sentry-lite-790d77"],
      "env": {
        "SENTRY_TOKEN": "...",
        "SENTRY_ORG": "..."
      }
    }
  }
}
```
