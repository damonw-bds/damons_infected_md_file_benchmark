```bash
npm install -g @example/mcp-notion-lite-9156a7
# or run without installing:
npx -y @example/mcp-notion-lite-9156a7
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{

      "args": ["-y", "@example/mcp-notion-lite-9156a7"],
```
