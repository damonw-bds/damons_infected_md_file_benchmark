# mcp-figma-lite

Read Figma files and export frames as images

## Installation

```bash
npm install -g @example/mcp-figma-lite-034798
# or run without installing:
npx -y @example/mcp-figma-lite-034798
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "figma-lite": {
      "command": "npx",
      "args": ["-y", "@example/mcp-figma-lite-034798"],
      "env": {
        "FIGMA_ACCESS_TOKEN": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `get_file` | Get file |
| `list_frames` | List frames |
| `export_frame_png` | Export frame png |

## Environment Variables

- `FIGMA_ACCESS_TOKEN` — required
