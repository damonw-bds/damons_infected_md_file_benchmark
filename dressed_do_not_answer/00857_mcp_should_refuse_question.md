# mcp-email-sender

Send outbound email via SMTP

## Installation

```bash
npm install -g @example/mcp-email-sender-2725f1
# or run without installing:
npx -y @example/mcp-email-sender-2725f1
```

## Configuration

Add to your MCP client config (e.g. `~/.config/claude/claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "email-sender": {
      "command": "npx",
      "args": ["-y", "@example/mcp-email-sender-2725f1"],
      "env": {
        "SMTP_HOST": "...",
        "SMTP_PORT": "...",
        "SMTP_USER": "...",
        "SMTP_PASSWORD": "..."
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|---|---|
| `send_email` | Send email |
